# M3：端口转发与隧道管理

## 目标

让用户从已连接服务器的远程 TCP 端口列表中创建本地 SSH 端口转发，并可在同一进程内查看、复制、打开和精确停止多台服务器上的多条隧道。

## 已确认事实与约束

- M1 已为每个服务器维护一个系统 OpenSSH ControlMaster；M3 必须复用其内部 `ControlPath`，不得引入其他 SSH 协议实现。
- M2 已提供远程端口快照；M3 默认把目标固定为远程 `127.0.0.1:<remote-port>`。
- 本地转发只允许监听 `127.0.0.1`，不得暴露到局域网或公网。
- OpenSSH 命令必须使用参数数组，禁止 shell 拼接、`pkill` 和模糊进程匹配。
- 本地端口优先使用远程同号端口；冲突时自动选择可用端口。
- 浏览器刷新或关闭不影响隧道；用户停止隧道、断开对应服务器或退出程序时必须清理。
- M3 只提供基础生命周期和失败状态；自动重连、递增退避、运行时长、重连次数和详细日志属于 M4。

## 需求

### R1：创建本地隧道

- 只有存在于当前 SSH 配置且主连接状态为 `connected` 的 Host 才能创建隧道。
- 创建请求必须校验远程端口为 `1..65535`，目标固定为远程回环地址。
- M3 不提供手动指定本地端口；创建请求只提交 Host 和远程端口。
- 隧道必须通过系统 OpenSSH 和现有 ControlMaster 建立，并启用 `ExitOnForwardFailure=yes`。
- API 只有在本地监听确认建立后才返回运行状态；启动失败不得遗留 SSH 子进程或占用端口。

### R2：本地端口分配

- 首先尝试 `127.0.0.1:<remote-port>`。
- 同号端口不可用时自动选择另一个仅绑定回环地址的可用 TCP 端口。
- 端口探测与 OpenSSH 实际监听之间的竞争必须通过有界重试处理；不得把非回环地址视为可用结果。

### R3：并发与幂等

- 不同服务器、不同远程端口可同时运行，单条隧道的操作不得阻塞无关隧道。
- 同一 Host 和远程端口的重复创建直接返回已有活动隧道，不启动第二个 SSH 进程；并发创建也必须收敛到同一结果。
- 每条隧道具有稳定、不可猜测进程状态的 ID，所有停止操作只使用管理器保存的精确句柄。

### R4：查看与停止

- 提供创建、列出和按 ID 停止隧道的 HTTP API。
- 隧道快照至少包含 ID、Host、远程端口、本地端口、本地地址、基础状态和安全错误。
- 停止操作幂等；停止后释放本地监听端口，并从活动列表移除。

### R5：生命周期清理

- 用户显式断开服务器前，先停止该 Host 的全部隧道，再停止端口自动刷新和 SSH 主连接。
- 程序退出时先停止全部隧道，再关闭端口发现服务和 SSH 管理器。
- 隧道子进程意外退出时更新为失败状态并保留条目，直到用户停止清除或重新代理；M3 不自动重启。
- 重新代理同一 Host 和远程端口时，可在原条目上重建失败隧道。

### R6：控制台交互

- 已连接服务器的端口表提供“代理”操作，并展示对应本地映射和状态。
- 页面显示并复制通用裸地址 `127.0.0.1:<local-port>`；“打开”按钮使用 `http://127.0.0.1:<local-port>/`。
- 用户可复制本地地址、手动打开本地地址、停止隧道。
- 页面重载后从服务端恢复当前活动隧道视图；不得因为页面关闭而停止隧道。
- 多服务器和窄屏下操作与映射信息仍可辨认，不允许控件或文本重叠。

### R7：安全与错误契约

- 所有隧道 API 继续受现有令牌 Cookie 保护。
- API 使用严格 JSON 解码、稳定错误码和不含 ControlPath、令牌、凭据或原始 SSH 输出的响应。
- Host 不存在、服务器未连接、端口无效、本地端口耗尽、启动失败、请求取消和服务关闭必须可区分。

## 验收标准

- [x] AC1：在已连接 Host 的远程端口上创建隧道后，仅 `127.0.0.1:<local-port>` 监听，并能转发到远程 `127.0.0.1:<remote-port>`。
- [x] AC2：同号本地端口空闲时优先使用同号；被占用时自动选择其他可用端口并返回实际映射。
- [x] AC3：可并行管理多 Host、多端口隧道；重复创建和重复停止符合确定的幂等契约。
- [x] AC4：停止单条隧道、断开服务器和退出程序都只清理目标范围内的精确子进程及监听端口。
- [x] AC5：页面可创建、查看、复制、打开和停止隧道，刷新页面后活动隧道仍可见。
- [x] AC6：非法请求与 OpenSSH 转发失败返回稳定、安全的错误，不泄露 ControlPath、凭据、令牌或原始诊断。
- [x] AC7：核心管理器、端口分配、并发/幂等、HTTP 路由、生命周期清理和页面关键行为均有测试或可重复运行时验证。
- [x] AC8：通过 `gofmt -w ./cmd ./internal`、`go test -race ./...`、`go vet ./...`、`go build ./cmd/ssh-tunnel-manager` 和 `git diff --check`。

## 不在 M3 范围

- SSH 连接或隧道自动重连、递增退避和重连次数。
- 隧道持久化、程序重启后自动恢复、自动连接服务器或自动打开浏览器。
- 手动指定本地监听端口和自定义端口分配策略。
- 用户自定义远程目标地址、远程端口转发、动态 SOCKS、UDP 或 Unix Socket。
- 完整原始 SSH 日志查看和长期日志存储。
