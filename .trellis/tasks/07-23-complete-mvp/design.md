# SSH 隧道管理器 MVP 整体验收设计

## 验收边界

父任务不重新实现 M1 至 M5，也不复制子任务的包级测试。它负责验证子任务状态、跨包数据流、安全不变量、运行时生命周期、发布安装链路和最终文档是否一致；发现整合缺陷时只做完成验收所需的最小修正。

## 跨阶段链路

```text
随机令牌认证
  → SSH Host 配置解析
  → OpenSSH ControlMaster 连接
  → 复用主连接执行 ss 端口发现
  → 创建 127.0.0.1 本地转发
  → 状态、日志与有界自动重连
  → 显式停止/断开/退出清理
  → Linux 发布包与用户级桌面安装
```

链路的状态所有权保持分层：`internal/sshconfig` 拥有配置解析，`internal/ssh` 拥有 ControlMaster 与受控命令，`internal/portdiscovery` 拥有端口快照和刷新，`internal/tunnel` 拥有转发与重连，`internal/preference` 拥有非敏感偏好，`internal/web` 只编排 API/页面，入口拥有认证和进程退出。

## 验证层次

1. **任务证据**：核对五个归档子任务状态与 PRD 验收项，确认阶段提交和规范均已保存。
2. **代码门禁**：格式、竞态测试、静态检查、常规构建和差异检查。
3. **交付门禁**：临时 HOME/XDG 安装回归、两个 ELF 架构、版本注入、精确包清单与 SHA-256。
4. **运行时冒烟**：使用正在运行的本地实例验证健康检查、认证边界、页面/API 与认证退出；退出后确认端口释放。
5. **安全审查**：搜索非回环监听、危险 SSH shell 拼接、全局进程清理、秘密/令牌落盘及工作流权限或顺序问题。
6. **文档一致性**：逐项对照 README、产品设计、架构、路线图、AGENTS 和 Trellis 规范，修复 M5 后的状态漂移。

真实远程 SSH 连接不在父验收执行范围内，避免外部副作用和凭据访问；连接、回退、转发、重连和清理通过已有可控运行时与竞态测试作为权威证据。

## 发现缺陷的处理

- 代码/脚本缺陷：回到实施，补回归测试后重跑全部门禁。
- 文档漂移：只更新拥有该事实的权威文档，不复制新的平行契约。
- 外部依赖不可用：若已有自动化覆盖，记录限制继续；若阻断核心验收，则不归档父任务。
- 发布产物只生成到被忽略的 `dist/`，不得提交二进制、创建标签或修改远端状态。

## 回滚与归档

整体验收提交只包含必要文档修正和父任务记录；若验收发现需大范围功能变更，应停止归档并创建独立子任务。所有验收通过后先提交，再由 Trellis 自动归档父任务和记录 journal。
