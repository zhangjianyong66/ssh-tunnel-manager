# 完成 SSH 隧道管理器 MVP

## Goal

交付一个可在 Ubuntu/Linux 本机运行的 Go 单文件 SSH 隧道管理器：用户通过仅绑定回环地址的 Web 控制台读取 SSH Host、连接远程 Linux 主机、发现远程 TCP 监听端口，并按需建立和管理本地端口转发。

## 已确认事实与约束

- 当前仓库只有 `cmd/ssh-tunnel-manager/main.go` 入口和产品/架构/路线文档，SSH 配置读取、端口探测、隧道、密钥环和偏好存储尚未实现。
- 使用 Go 1.22+、系统 OpenSSH；不修改 `~/.ssh/config`，复用其配置、ssh-agent、known_hosts 和 ProxyJump 能力。
- Web 控制台与本地代理端口只监听 `127.0.0.1`；令牌由 `crypto/rand` 生成并通过 HttpOnly、SameSite Cookie 认证。
- 密码和私钥口令只进入 Linux Secret Service/GNOME Keyring，不得明文落盘、进入命令行参数或日志。
- 远程端口探测优先 `ss -ltnp`，权限不足退化为 `ss -ltn`，MVP 默认转发目标为远程 `127.0.0.1`。
- 程序退出或显式停止时清理 SSH 子进程和隧道；浏览器关闭不影响程序与隧道。
- 验证基线为 `gofmt -w ./cmd ./internal`、`go test ./...`、`go vet ./...`、`go build ./cmd/ssh-tunnel-manager`。

## 交付组织决策

- 本项目不作为一个一次性大实现任务推进，而是由父任务统筹、按路线图拆分为多个可独立验收的子任务。
- 子任务按 M1 → M2 → M3 → M4 → M5 顺序逐个实施；前一阶段的稳定接口和测试是后一阶段的输入。
- 每个子任务单独完成需求、设计、实现、验证和提交；父任务只负责跨阶段验收和整体收尾。

## 需求（待访谈收敛）

### 功能

- 读取并展示系统 SSH Host 配置，支持手动连接/断开多台服务器。
- 探测并展示远程 TCP 监听端口，支持手动刷新和可选自动刷新。
- 多服务器、多端口并行代理；本地端口同号优先，冲突时选择可用端口。
- 展示隧道状态、运行时长、重连次数和错误；支持停止、复制本地地址和手动打开浏览器。
- SSH 连接中断时对运行中的隧道执行有界自动重连，失败后要求人工处理。
- 提供可读错误和可展开的脱敏原始 SSH 日志；保存非敏感界面偏好，但不自动连接或恢复隧道。

### 安全与兼容

- 所有业务 API 需要令牌 Cookie；写操作支持幂等标识并返回结构化错误。
- OpenSSH 使用参数数组和受控 askpass/输入通道，禁止 shell 拼接和秘密泄露。
- 不支持公网/局域网暴露、远程 Agent、UDP/Unix Socket、修改 SSH 配置，以及 macOS/Windows 密钥环。

## 验收标准（初稿）

- [ ] 在 Ubuntu/Linux 上可启动本地控制台并完成令牌认证。
- [ ] 可从 `~/.ssh/config` 选择 Host，建立和断开 SSH 连接并显示状态/错误。
- [ ] 可发现远程 TCP 监听端口，并在 `ss -ltnp` 不可用时退化到 `ss -ltn`。
- [ ] 可创建、查看、停止多条本地端口转发，端口冲突按约定分配并可打开本地地址。
- [ ] SSH 断开后的重连、退出清理、日志脱敏和密钥环存储通过测试或可重复验证。
- [ ] 通过格式化、单元测试、静态检查和构建验证。
