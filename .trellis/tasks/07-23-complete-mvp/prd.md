# 完成 SSH 隧道管理器 MVP

## Goal

完成 Ubuntu/Linux 本地 SSH 隧道管理器 MVP 的跨阶段整体验收：确认 M1 至 M5 已交付能力能够组成安全、可运行、可安装和可维护的完整产品，并归档父任务。

## 已交付范围

- M0：Go 单进程、本地回环 Web 控制台、随机令牌与 Cookie 认证。
- M1：读取系统 OpenSSH 配置，管理多 Host ControlMaster，支持 askpass 与 Linux Secret Service。
- M2：通过既有主连接执行 `ss -ltnp`，权限不足时退化为 `ss -ltn`，支持手动和按 Host 自动刷新。
- M3：创建和管理多 Host、多端口本地转发，同号端口优先、冲突自动分配，并精确清理子进程。
- M4：隧道有界自动重连、共享主连接恢复、状态/运行时长/日志、XDG 非敏感偏好和控制台体验。
- M5：Linux amd64/arm64 发布包、SHA-256、用户级安装/卸载、桌面入口、认证退出和标签自动发布流程。

五个子任务均已完成独立需求、设计、实现、质量门禁、提交和归档。

## Requirements

### 完整用户流程

- 程序只监听回环地址，用户经随机令牌进入控制台，读取 `~/.ssh/config` 中的显式 Host。
- 用户手动连接服务器后可发现远程 TCP 监听端口、创建本地转发、复制或打开本地地址，并可停止隧道或断开 Host。
- 页面关闭不影响连接和隧道；显式退出按隧道、端口发现、SSH、HTTP 顺序清理全部资源。
- 临时故障按固定上限自动恢复，永久错误转为人工处理，不因单个隧道故障退出整个程序。

### 安全与数据边界

- Web、转发和远程默认目标均限制为回环地址；不得新增公网、局域网、容器映射或反向代理暴露。
- 系统 OpenSSH 是唯一 SSH 协议实现；命令使用参数数组，复用用户配置、ssh-agent、known_hosts 和 ProxyJump，不修改 `~/.ssh/config`。
- 密码和私钥口令只通过受控通道和 Secret Service 处理，不进入命令参数、普通配置、日志、HTTP 响应或发布包。
- 非敏感偏好使用权限受限的 XDG JSON；程序启动不自动连接、探测或恢复隧道。

### Linux 交付

- amd64/arm64 发布包内容、程序版本、ELF 架构和 SHA-256 可重复验证。
- 安装与卸载只操作当前用户 HOME 下的 XDG 路径，不使用 `sudo`、不创建 systemd 服务、不删除配置或凭据。
- 桌面入口自动打开浏览器，并允许从已认证控制台触发优雅退出。
- `v*` 标签发布必须先通过完整质量门禁，Release 上传完整后才转为正式状态。

## Out of Scope

- 在验收中连接用户真实远程服务器、读取或写入真实凭据、创建版本标签、推送远端或发布 GitHub Release。
- macOS/Windows 密钥环适配、系统级安装、systemd、自动开机启动、容器和包管理器仓库。
- 公网/局域网访问、远程 Agent、UDP、Unix Socket、自动连接和自动恢复上次隧道。
