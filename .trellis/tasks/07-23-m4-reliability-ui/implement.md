## 审查重点与回滚点

- 子任务 1 先建立可测试状态和脱敏边界；若诊断无法在进入隧道层前可靠脱敏，暂停日志 API，不向页面暴露原始内容。
- 子任务 2 不得让 Stop/StopHost/Close 后重新启动 SSH 或监听端口；发现此类竞态时回滚自动重连，保留状态与日志基础。
- 子任务 3 的配置错误不得阻断 SSH 和隧道；偏好接入可单独回滚为进程内默认关闭。
- 子任务 4 只消费服务端快照和日志，不在浏览器复制重连状态机；页面可单独回滚而不影响后端运行隧道。
- 最终确认所有进程只有一个 `Wait` 调用者、所有后台等待可取消、所有本地监听仍固定为 `127.0.0.1`。
