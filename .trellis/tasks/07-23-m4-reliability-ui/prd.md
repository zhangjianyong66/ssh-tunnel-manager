# M4：可靠性与控制台体验

## 目标

在不改变现有手动连接和隧道安全边界的前提下，让运行中的 SSH 隧道能够从短暂连接故障中自动恢复，并在控制台中提供清晰的状态、运行时间、重连次数和脱敏诊断信息。

## 已确认事实与约束

- M1 已由 `internal/ssh` 管理每台服务器的系统 OpenSSH ControlMaster，异常退出时保留安全错误和脱敏诊断；无交互参数的 `Connect` 会尝试复用 Secret Service 中已保存的凭据。
- M2 已提供每台服务器默认关闭、固定 10 秒间隔的端口自动刷新，但开关目前只保存在进程内存中。
- M3 已由 `internal/tunnel` 独占隧道 ID、目标幂等键、本地端口、进程句柄和异常退出监控；失败条目保留原 ID，并可在同一条目上重建。
- 本地 Web 服务和全部转发端口继续只监听 `127.0.0.1`；不得修改 SSH 配置、绕过主机密钥检查、使用 shell 拼接或模糊清理进程。
- 浏览器刷新或关闭不得影响服务器连接、自动刷新、隧道或重连流程。
- 用户显式停止隧道、断开服务器或退出程序时必须取消相关重连，不得把显式操作误判为故障。
- 所有面向页面的错误必须安全可读；原始 SSH 诊断必须先脱敏，并受到长度和数量限制。

## 需求

### R1：有界自动重连

- 仅为发生意外故障且此前处于运行状态的隧道自动恢复；不得自动恢复程序重启前的连接或隧道。
- 单条转发进程意外退出但 SSH 主连接仍可用时，重建该隧道。
- SSH 主连接意外退出时，协调同一 Host 下仍需运行的隧道：先恢复 ControlMaster，再恢复这些隧道，避免每条隧道各自重复连接服务器。
- 重连使用递增退避和固定尝试上限；成功后回到运行状态，耗尽次数或遇到不可重试错误后进入需要人工处理的失败状态。
- 每次故障最多自动尝试 5 次，退避间隔依次为 1、2、4、8、16 秒；恢复后稳定运行满 60 秒，下一次故障才重新获得完整重试额度。
- 重连次数按实际尝试累计，在隧道条目的生命周期内不因成功恢复而清零；失败额度按连续故障周期单独计算。
- 认证失败、主机密钥异常、配置错误、缺少本地依赖或需要交互凭据均视为不可重试错误，立即转为需要人工处理。
- 自动重连不得弹出浏览器凭据对话框；可复用 ssh-agent、SSH 配置和已保存的 Secret Service 凭据。缺少凭据或认证失败时停止自动尝试并提示用户手动连接。

### R2：状态与可观测性

- 隧道快照增加运行起始时间、当前连续运行时长所需时间戳、累计重连次数和下一次重试时间。
- 状态应至少区分启动中、运行中、等待重连、正在重连、停止中和失败，页面显示自然中文而不是内部状态值。
- 重连成功时保留累计重连次数并清除当前错误；重新建立后的连续运行时长从成功时重新计算。
- 列表轮询不得修改状态真相，页面刷新后应从服务端恢复当前状态。

### R3：脱敏日志

- 每条隧道提供可展开的近期事件和 SSH 诊断，用于解释启动、退出、等待重试、重连成功及最终失败。
- 日志只保存在当前进程内存中，每条隧道最多保留最近 100 条，并设置总字节上限；停止隧道或退出程序后清除，不写入磁盘。
- 日志必须过滤访问令牌、密码、私钥口令和运行时 ControlPath 等敏感内容；HTTP 列表快照不得内联原始诊断。
- 日志读取使用独立、受令牌 Cookie 保护的 API，并对不存在的隧道返回稳定错误。

### R4：偏好持久化

- 仅保存每台服务器的端口自动刷新开关，写入 XDG 配置目录下的非敏感 JSON 配置。
- 程序启动后不得自动连接服务器，也不得仅因保存的开关而启动远程操作。
- 用户手动连接服务器后恢复该 Host 保存的自动刷新设置；关闭开关后立即停止刷新并更新配置。
- 配置缺失时使用默认关闭；配置损坏或不可写时安全降级并向用户返回可读错误，不得影响手动连接和隧道的基础能力。

### R5：控制台体验

- 隧道总览展示服务器、远程端口、本地映射、状态、连续运行时长和累计重连次数。
- 等待重连时显示下一次尝试的倒计时或明确时间；最终失败时提供手动重试和停止/清除入口。
- 日志按需展开和加载，默认不占据主要操作空间；窄屏下状态、映射和操作不得重叠。
- 保持现有复制地址和手动打开浏览器行为，不自动打开目标地址。

## 验收标准

- [x] AC1：单条转发进程意外退出后按有界退避自动恢复，ID 保持不变，状态、运行起始时间和重连次数正确。
- [x] AC2：ControlMaster 意外退出时，同一 Host 只执行一组主连接恢复操作，随后恢复该 Host 仍需运行的全部隧道。
- [x] AC3：显式停止、显式断开和程序退出会取消重连，且不会遗留 SSH 子进程、监听端口或后台任务。
- [x] AC4：认证失败、缺少凭据和重试耗尽会停止自动尝试并显示可执行的人工处理提示。
- [x] AC5：日志 API 和控制台可查看有界的近期事件及脱敏 SSH 诊断，不泄露凭据、令牌或 ControlPath。
- [x] AC6：自动刷新开关跨程序重启保存，但启动时不自动连接；手动连接后才按保存值恢复刷新。
- [x] AC7：控制台正确显示状态、连续运行时长、重连次数和日志，桌面与窄屏均无明显重叠或不可操作控件。
- [x] AC8：通过并发、竞态、HTTP、安全和生命周期测试，以及项目完整格式化、测试、静态检查和构建门禁。

## 不在 M4 范围

- 程序重启后自动连接服务器、恢复隧道或自动打开浏览器。
- 保存本地 Web 端口、端口分配策略、日志级别或其他界面偏好。
- 在 M4 新增凭据删除界面、修改 SSH 配置、远程 Agent 或非 TCP 转发。
- 无限重试、后台守护进程、跨设备同步或将控制台/转发端口暴露到非回环地址。
- 跨程序重启保存 SSH 诊断或隧道事件日志。
