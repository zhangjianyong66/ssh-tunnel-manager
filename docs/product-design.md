# 产品设计

## 1. 产品概述

SSH 隧道管理器解决以下场景：开发者通过 SSH 登录远程机器，在远程机器启动 Web 服务或其他 TCP 服务，但本地浏览器无法直接访问远程回环地址。程序在本地提供一个 Web 控制台，帮助用户发现远程监听端口并建立 SSH 本地端口转发。

产品不要求远程服务器安装 Agent，也不依赖 Chrome 插件。浏览器只作为本地控制界面和目标 Web 服务的访问入口。

## 2. 目标用户与目标

- 目标用户：使用 SSH + Codex/终端在远程 Linux 机器上开发的个人开发者。
- 核心目标：用几次点击完成“连接服务器 → 查看监听端口 → 建立本地代理 → 打开本地地址”。
- 非目标：公网反向代理、多人协作、通用 VPN、UDP 转发和远程服务器管理。

## 3. 已确认的用户流程

1. 用户在本地启动程序。
2. 程序监听 `127.0.0.1:8765`，输出带随机令牌的控制台 URL。
3. 用户在页面选择 `~/.ssh/config` 中的 SSH Host。
4. 用户手动点击“连接”，程序使用系统 OpenSSH 登录目标服务器。
5. 页面展示远程 TCP 监听端口，首次连接后加载一次。
6. 用户手动刷新端口列表，或按需开启自动刷新。
7. 用户点击某个端口的“代理”。
8. 程序优先使用相同端口作为本地端口；冲突时自动选择可用端口。
9. 页面显示完整映射和“打开”按钮。用户点击后才打开浏览器。
10. 页面关闭不影响连接和隧道；用户点击“停止”或退出程序才关闭。
11. SSH 连接中断后，程序自动重连正在运行的隧道；多次失败后转为需要人工处理。

## 4. 功能范围

### MVP 必须具备

- 读取并展示系统 SSH Host 配置；
- 手动连接和断开多台服务器；
- 通过 `ss -ltnp` / `ss -ltn` 探测远程 TCP 监听端口；
- 多服务器、多端口同时代理；
- 本地端口同号优先、冲突自动换端口；
- 查看隧道状态、停止隧道、复制本地地址、点击打开浏览器；
- 连接断开后的有界自动重连；
- 可读错误提示和可展开原始 SSH 日志；
- Linux Secret Service / GNOME Keyring 凭据持久化；
- 保存界面偏好，但不自动连接或自动恢复隧道。

### 暂不支持

- Chrome 扩展；
- 公网、局域网访问控制台或代理端口；
- 远程 Agent；
- UDP、Unix Socket；
- 修改 `~/.ssh/config`；
- 自动连接上次服务器；
- 自动打开浏览器；
- macOS Keychain 和 Windows Credential Manager。

## 5. 安全要求

- 所有 HTTP 监听默认绑定 `127.0.0.1`。
- 访问令牌使用 `crypto/rand` 生成，仅在进程内存中有效；首次 URL 换取 HttpOnly、SameSite Cookie。
- 密码和私钥口令进入系统密钥环，不进入 SQLite/JSON、命令行参数、环境变量或日志。
- 调用 OpenSSH 时不得把密码拼接到命令行；使用受控的 askpass/输入通道。
- 原始 SSH 输出必须过滤秘密值和访问令牌。
- 不自动执行 `sudo`，端口探测不要求远程提权。
- 用户显式停止或程序退出时，清理所有 SSH 子进程和监听端口。

## 6. 关键用户界面

- 服务器列表：Host 别名、连接状态、最近错误、刷新配置。
- 服务器详情：连接/断开、端口刷新、自动刷新开关、端口表。
- 端口表：远程端口、进程（可用时）、代理状态、本地地址、复制/打开/停止操作。
- 隧道总览：按服务器分组显示映射、运行时长、重连次数和错误详情。
- 设置：本地 Web 端口、端口分配策略、密钥环凭据删除、日志级别。
