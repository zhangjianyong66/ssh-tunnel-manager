# 开发路线

## M0：项目骨架（已完成）

- Go 单文件入口；
- 本地回环 Web 服务；
- 随机令牌和 Cookie 认证；
- 文档固化产品边界和安全约束。

## M1：SSH 配置与连接（已完成）

- 解析 `~/.ssh/config`，展示 Host 别名；
- 使用 OpenSSH 建立可观测的连接；
- 统一错误分类和日志脱敏；
- 集成 Linux Secret Service。

## M2：端口发现（已完成）

- 执行和解析 `ss -ltnp`；
- 权限不足时退化到 `ss -ltn`；
- 页面手动刷新和可选自动刷新。

## M3：单端口与多端口隧道（已完成）

- 本地同端口优先、冲突自动分配；
- 多服务器、多端口并行管理；
- 停止、复制地址、手动打开浏览器；
- 子进程精确清理。

## M4：可靠性与体验（已完成）

- 自动重连和递增退避；
- 运行时长、重连次数、状态流；
- 可读错误与原始日志查看；
- 保存偏好但不自动恢复连接。

## M5：交付

- Linux amd64/arm64 构建；
- 安装脚本和用户级桌面入口；
- `go test ./...`、`go vet ./...`、构建和安全回归测试；
- 后续再评估 macOS/Windows 密钥环适配。
